# Videos are fresh on every visit

Supersedes the "up to a day" part of [0001](0001-static-site-with-daily-rebuild.md). Simón wants a new upload to show up as soon as someone reloads `/videos`, not after the next rebuild (and the daily rebuild was never set up). Browsers cannot read YouTube's feed directly (no CORS), so one small server route, `/api/videos.json`, reads the same free per-channel feed on each request, with Vercel's CDN caching each answer for five minutes. The page is still built ahead of time with the Videos of the build, so it reads without JavaScript (ADR 0002) and keeps that list if the route fails; after loading it swaps in the fresh list when it differs. We accept one runtime route and its failure mode in exchange for freshness; YouTube's own feed can still lag a few minutes behind an upload. The home page's Latest feed and navigator keep the Videos of the build.
